## BulkIn v1.1.0

Aplikasi Android untuk mencatat makanan, kalori, dan berat badan harian untuk program bulking.

### Baru di v1.1.0
- **Widget layar utama** dalam 4 ukuran, plus tombol **+ Catat makan** yang membuka form catat makanan:
  - **Lengkap (3×3)**: kalori, sisa target, protein, berat, tombol
  - **Ringkas (2×2)**: kalori, persen, bar progres, tombol
  - **Baris (4×1)**: satu baris kalori + bar + tombol
  - **Mini (2×1)**: kalori + bar (ketuk untuk buka aplikasi)

### Fitur
- **Harian**: catat makanan per waktu makan, progres kalori vs target, timbangan harian
- **Progres**: grafik berat & kalori (7/30/90 hari), tren kg/minggu
- **Makanan**: ±65 makanan bawaan, bisa tambah/koreksi sendiri
- **Tanya AI**: perkiraan kalori & protein makanan yang belum ada di daftar
- **Kebutuhan kalori**: dihitung dari data kamu sendiri
- **Offline**: catatan tetap tersimpan tanpa internet, sinkron otomatis saat online

### Pasang
1. Unduh [BulkIn-v1.1.0.apk](BulkIn-v1.1.0.apk) (klik file → **Download raw file**).
2. Buka file di HP Android → izinkan "Instal dari sumber tidak dikenal" bila diminta.
   Sudah punya versi lama? Langsung pasang di atasnya, data & login tetap ada.

### Pasang widget
Tekan lama area kosong di layar utama → **Widget** → cari **BulkIn** → pilih ukuran → seret ke layar utama.
